# AME Bazaar AI Video Engine - PROJECT VISION
Version: 1.0

# PROJECT VISION

--------------------------------------------------
MISSION
--------------------------------------------------

The AME Bazaar AI Video Engine is an AI-first open-source documentation framework designed to be the single source of truth for any modern AI system (ChatGPT, Claude, Gemini, Google Flow, Google Veo, Runway, Kling, Pika, Sora, etc.). 

Every AI should be able to read and understand this repository to produce professional, cinematic commercials without needing additional human explanations or repetitive long prompts.

--------------------------------------------------
VISION
--------------------------------------------------

This repository functions as a professional open-source software project. It provides structured, modular documentation instead of ad-hoc prompt templates. The repository itself teaches reasoning engines (AI systems) how to generate professional cinematic commercials using standardized knowledge, workflows, and compiler pipelines.

--------------------------------------------------
DESIGN PRINCIPLES
--------------------------------------------------
- **Documentation First**: All system rules are defined in version-controlled markdown.
- **Knowledge First**: Business and cinematic facts are separated from the code/prompts.
- **Repository First**: The repository is the permanent brain; chat conversation is temporary.
- **AI Interoperability**: Formatted to be readable by any current or future LLM/video generator.
- **Token Efficiency**: Reuses modular structures to minimize token usage and maximize execution speed.

--------------------------------------------------
PRIMARY GOAL
--------------------------------------------------

Eliminate repetitive prompting. Instead of pasting large system instructions, the user can instruct any capable AI to:
1. Read the repository.
2. Understand the architecture.
3. Follow the documented workflow.
4. Generate the requested production package.

--------------------------------------------------
OPEN-SOURCE FRAMEWORK PRINCIPLES
--------------------------------------------------
The engine is architected as a generalized open-source framework for AI video generation. Brand-specific details (e.g., AME Bazaar) are treated as pluggable reference implementations under the knowledge directories, keeping the core system modular and adaptable to other brands.

--------------------------------------------------
LONG-TERM OBJECTIVE
--------------------------------------------------

Establish this repository structure as the global standard framework for AI-generated commercial video production—reducing prompt lengths, improving visual quality, and ensuring multi-scene continuity across diverse AI video models.

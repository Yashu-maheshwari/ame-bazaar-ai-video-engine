# Maheshwari Counsel — Legal Source Registry

## Purpose

This directory is the source registry for the Maheshwari Counsel Lawyer AI profile. Legal Reel content must be grounded in current, verifiable legal sources. The AI must not treat a third-party bare-act compilation as the final authority when an official government source is available.

## Source hierarchy

1. Current official legislation / India Code / Gazette material.
2. Official Supreme Court / High Court / statutory-authority material for judgments, rules, notifications and current procedural positions.
3. Reputable bare-act repositories such as Your Lordships only as a convenient secondary reading/index source.
4. Never use an unsourced blog, social post or generated summary as the sole legal source for a published Reel.

Use this source as a convenient reading/download index, but verify the current text and amendments against an official source before publishing legal content.

## Mandatory publication rule

For every Maheshwari Counsel Reel:

- Record the source Act / provision / judgment used.
- Verify that the source is current for the publication date.
- Feed only the verified fact sheet into the Reel Director.
- The Reel Director may simplify language and structure but must not create a new legal proposition.
- If the source does not support a statement, the statement must not appear in the Reel.
- Current-law topics require source verification before publication.
- Professional-conduct / non-solicitation guardrails remain mandatory.

## Status

This registry is a navigation and source-control layer. It intentionally does not copy third-party PDF files into the public repository. Static copies can become outdated; official source links are retained so current text can be verified before publication.

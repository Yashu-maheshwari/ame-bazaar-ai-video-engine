# AI ACCESS PROTOCOL

--------------------------------------------------
PURPOSE
--------------------------------------------------

This repository is designed to be used by any AI system (Antigravity, Gemini, Claude, ChatGPT, and future AI models).

--------------------------------------------------
PRIMARY GOAL
--------------------------------------------------

Generate Google Flow prompts that create:
- The original AME Bazaar showroom look.
- Consistent frame-to-frame continuity.
- Connected long-form video shoots.
- Reusable scene packages.

--------------------------------------------------
USAGE RULES
--------------------------------------------------
1. **Read Repository Manifest**: Load `manifest.md` to map repository architecture.
2. **Read AI Instruction Protocol**: Load `ai_instruction_protocol.md` for sequencing rules.
3. **Load Only Required Knowledge**: Filter context using the Context Loader (minimize tokens).
4. **Prioritize Reference Assets**: Use reference images and reference videos before descriptive text.
5. **Generate Google Flow Production Package**: Produce standard output blocks.
6. **Maintain Strict Continuity**: Keep scene elements identical across all frames.

--------------------------------------------------
OPERATIONAL CONSTRAINTS
--------------------------------------------------
- Do not depend on any single AI tool.
- Do not rewrite the repository for each model.
- Do not load unnecessary files.
- Minimize tokens, maximize output quality.

--------------------------------------------------
CAMPAIGN / REEL WORKFLOW
--------------------------------------------------
If the request is for a reel or commercial:
- Identify required reference assets.
- Identify store layout requirements.
- Identify product focus.
- Generate scene-by-scene prompt blocks.
- Ensure Scene 2 continues Scene 1, Scene 3 continues Scene 2.

The repository is the source of truth. The AI is only the compiler.

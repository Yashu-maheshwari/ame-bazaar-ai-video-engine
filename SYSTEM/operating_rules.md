# AME Bazaar AI Video Engine - OPERATING RULES
Version: 1.0

# OPERATING RULES

You must always work from the GitHub repository.

Never start by asking generic marketing questions.

Before asking the user anything, search the repository for existing knowledge.

Always follow this priority:
1. Repository Knowledge
2. Existing Campaign Library
3. Brand Bible
4. Product Library
5. Store Bible
6. Character Bible
7. Camera Bible
8. Previous Video Projects

Only ask the user for information that does not already exist.

---

## Repository First Policy

Whenever the user requests:
- Create Reel
- Create Advertisement
- Create Fashion Shoot
- Create Campaign
- Create Product Video
- Launch New Collection
- Instagram Reel
- Commercial
- Video Prompt

You MUST first search the repository.

Never ask questions that can be answered from repository knowledge.

## Missing Information Policy

If required information is missing:
- Do NOT immediately ask multiple questions.
- Instead, identify exactly which knowledge file is missing.
- Suggest creating or updating that knowledge file.

Example:
Missing Product Information -> Create `knowledge/products/women/kurtis.md` instead of asking random questions.
